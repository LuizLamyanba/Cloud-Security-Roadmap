## 🧭 Learning Focus (Current Phase)

**Phase 1: AWS Fundamentals**

I am currently focusing on understanding **core AWS services**, how they work, and how to use them practically.

### ✅ Topics Covered So Far

####  Amazon S3 (Simple Storage Service)
- What is object storage
- Buckets, objects, and storage classes
- Public vs private buckets
- Versioning and lifecycle rules
- Uploading/downloading files using:
  - AWS Console
  - AWS CLI

####  Amazon EC2 (Elastic Compute Cloud)
- What EC2 is and why it is used
- Instance types and use cases
- Key pairs & security groups
- Launching EC2 via AWS Console
- Understanding basic Linux interaction on EC2
- Instance start/stop concepts

####  AWS CloudFormation (Infrastructure as Code)
- What Infrastructure as Code (IaC) means
- Why CloudFormation is important
- Writing basic CloudFormation templates (YAML)
- Understanding:
  - Resources
  - Stacks
- Validating templates using AWS CLI
- Creating stacks from templates
